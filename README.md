# Airbnb Market Analysis – Power BI Dashboard

## Project Overview
This project analyzes Airbnb listing data across 10 European cities to explore pricing patterns, room types, and customer satisfaction. An interactive Power BI dashboard was developed to present key insights and help users understand differences between cities and listing characteristics.

## Dashboard Pages

### 1. Overview
Provides a general summary of the dataset through key performance indicators and comparisons between cities and listing types.

### 2. Price Influencers
Explores factors related to Airbnb prices, including city, room type, and weekday versus weekend listings.

### 3. Satisfaction
Examines customer satisfaction and compares listing characteristics to identify patterns in guest ratings.

## Key Findings
- Amsterdam has the highest average nightly prices, while Athens has the lowest in the analyzed weekday data.
- The average nightly price across the dataset is approximately 134.
- Entire homes and apartments represent the largest share of listings, followed by private rooms.
- Airbnb prices vary across cities and between weekdays and weekends.

## Data Model
The project uses a structured data model to organize listing information and support comparisons across cities, room types, and day types.

## Tools & Technologies
- **Power BI Desktop:** Dashboard development and data visualization.
- **Python (Pandas):** Data preparation and analysis.
- **Jupyter Notebook:** Data exploration and preprocessing.

## Dataset
The dataset is publicly available on Kaggle:

[Airbnb Prices in European Cities – Kaggle](https://www.kaggle.com/datasets/thedevastator/airbnb-prices-in-european-cities)

It contains Airbnb listing data from 10 European cities, including weekday and weekend information.

## How to Use
1. Download or clone this repository.
2. Open `Airbnb Dashboard.pbix` using Power BI Desktop.
3. If prompted, update the data source paths to match the location of the CSV files.
4. Navigate through the three dashboard pages to explore the results.
